# 🏋️ FitLog — Workout Library & Plan Tracker

## 📌 Project Overview

**FitLog** is a modern and responsive workout management web application that helps users discover exercises, explore detailed workout information, create a personalized daily workout plan, and save workouts for later.

The application provides a clean, dark-themed fitness interface with interactive workout cards, dynamic statistics, sorting functionality, toast notifications, and responsive layouts for mobile, tablet, and desktop devices.

---

## 🛠️ Technologies Used

* **Next.js** — Frontend framework and application routing
* **React.js** — Building reusable and interactive UI components
* **JavaScript** — Application logic and functionality
* **Tailwind CSS** — Responsive styling and modern UI design
* **Next.js App Router** — Page navigation and dynamic workout details
* **React Context API** — Managing workout plan and saved workout state
* **LocalStorage** — Persisting plan and saved workout data
* **REST API** — Fetching workout/exercise data
* **Vercel** — Deployment

---

## ✨ Key Features

### 1. 🏋️ Workout Library

Browse a complete collection of workouts in a responsive card-based layout. Each workout displays its image, category, equipment, duration, calories, and rating.

### 2. 📋 Today's Workout Plan

Users can add workouts to their daily plan and manage them from the **My Plan** page. The plan includes live statistics for total exercises, workout duration, and calories.

### 3. 💾 Save Workouts for Later

Users can save their favorite workouts for future reference. Saved workouts are organized separately and can be accessed easily from the **My Plan** page.

### 4. 📊 Workout Tracking

Users can mark planned workouts as **Done** or remove them from their plan. The application provides toast notifications and dynamically updates workout statistics after each action.

### 5. 📱 Responsive & Interactive UI

FitLog is fully responsive across mobile, tablet, and desktop devices. It includes workout detail pages, sorting options, loading states, empty states, navigation badges, toast notifications, and a custom 404 page.

## 🎯 Main Pages

* **Home Page** — Workout library and hero section
* **Workout Details Page** — Complete information and instructions for each workout
* **My Plan Page** — Today's Plan and Saved workouts
* **404 Page** — Custom page for invalid routes
